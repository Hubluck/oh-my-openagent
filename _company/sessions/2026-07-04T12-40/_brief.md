# 📋 작업 브리프

**원 명령:** 핸드폰 폴더로 쓸 신발 아비트리지 엑셀(`포이즌 × 리테일 통합표`, 2026-07-04 생성)을 직관적으로 시각화해서 보고 싶다.

## 요약
포이즌 시장가와 국내 리테일 소싱가를 대조한 신발 리셀 데이터(매칭 2,469건 / 마진＋ 1,131건)를,
모바일에서 한눈에 보는 자체 완결형(single-file) 인터랙티브 대시보드로 만들었다.

## 산출물
- `dashboard.html` — 오프라인·자체 완결형 HTML. 폰 브라우저로 바로 열림. 외부 의존성 없음(데이터 인라인).

## 데이터 출처
- 원본: `다사이트 통합표 (포이즌 × 리테일)` xlsx · 생성 2026-07-04 · 포이즌 16,840코드 대조
- 시트: 요약 / 아비트리지(1131) / 수요TOP / 전체매칭(2469)
- 대시보드에는 `전체매칭(2469)` 전체를 압축 임베드(브랜드·매장 인덱싱, 수치 반올림).

## 핵심 지표 설계
- **소싱가** = 국내 리테일 최저가, **시장가** = 포이즌 거래 기준가, **마진** = 시장가 − 소싱가(수수료·배송 제외).
- 기본 정렬을 원본 엑셀의 "마진 순"이 아니라 **추천순(마진 × 수요)** 으로 변경.
  - 이유: 엑셀 TOP1(호카 로켓 X 3, +38만)은 **거래량 0**(안 팔림)이라 마진만 보면 오판. 수요 가중으로 실제로 팔리는 상품을 상단에 노출.
  - 가중식: `score = margin × (1 + log10(volume + 10))`.
- 손해(마진 −)는 기본 숨김. 상단 토글로 전체 보기 가능.

## 구성
1. KPI 4칸(매칭 수·마진＋건수·평균/최고 마진)
2. 기회 지도(산점도): 가로=수요, 세로=마진, 우상단=꿀 존. 점 탭 시 상품 정보 표시.
3. 기회 목록(카드): 브랜드·매장 → 상품명 → 소싱가→시장가 → 마진(+%) → 수요 막대.
4. 검색·브랜드칩·정렬·손익 토글·다크모드.

## 검증
- Chromium 헤드리스로 렌더 확인: JS 오류 없음, 카드 30개 렌더, KPI(2,469 / 1,131 / ₩21,173 / ₩383,741) 일치, 산점도 탭→상품 표시 동작, 라이트/다크 모두 정상.
- 확인법: 폰에서 `dashboard.html`을 열어 정렬을 "마진 큰 순"↔"추천순"으로 바꾸면 순서가 달라지고, 산점도 점을 누르면 상품이 뜬다.
