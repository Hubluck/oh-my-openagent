# 📥 Sources (원본 자료)

여기에 **원본 자료**를 넣는다. (논문 PDF, 아티클 텍스트, 마크다운 메모, 링크 모음 등)

규칙:
- 이 폴더의 파일은 **원본**이며 LLM이 수정하지 않는다 (`raw/`는 불변).
- 자료를 추가한 뒤 "ingest 해줘"(`/wiki-ingest`)라고 하면 LLM이 읽고 `wiki/sources/`에 요약 페이지를, `wiki/concepts·entities`에 파생 페이지를 만든다.
- 웹 링크만 있으면 `_links.md` 같은 파일에 URL 목록만 적어둬도 된다.
- 이미지는 옆 폴더 `raw/assets/`에 둔다.
