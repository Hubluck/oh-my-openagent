# (Source) 웰빙 메모

> 원본: `raw/sources/웰빙-원본.md` (개인 메모, 한국어)

## 3줄 요약
- 웰빙 = 몸과 마음이 모두 건강하고 균형 잡힌 상태. 단순히 병이 없는 것을 넘어 **삶의 질·만족**까지 포함.
- 4개 축으로 구성: 신체적 건강 / 정신적 건강 / 사회적 관계 / 삶의 만족도.
- 실천 예: 건강식, 요가·명상, 워라밸 추구.
