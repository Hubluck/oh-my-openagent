# Ingest / Query / Lint

> [[llm-wiki]]를 운영하는 3가지 핵심 동작.

## Ingest (수집)
원본을 읽고 핵심 추출 → 출처 요약 페이지 생성 → 개념·엔티티 페이지에 통합 → 링크 갱신 → 충돌 표시.

## Query (질의)
관련 페이지 검색 → **출처를 명시**해 답변 → 재사용 가치 있는 답은 종합 페이지로 영구 저장.

## Lint (점검)
고아 페이지·오래된 주장·빠진 링크·구조 구멍을 주기적으로 찾아 보고(삭제는 제안만).
