# Ingest / Query / Lint

> [[llm-wiki]]를 운영하는 3가지 핵심 동작.

## Ingest (수집)
원본 읽기 → 핵심 논의 → 출처 요약 페이지 작성 → 관련 개념·엔티티 페이지 갱신 → `log.md`에 append.
- 자료 하나가 기존 **10~15개 페이지**를 건드릴 수 있다.
- 대부분의 갱신은 **append-only**라 merge 충돌이 적다. **멱등성**: 같은 자료를 순서만 바꿔 다시 넣어도 같은 상태로 수렴해야 한다.

## Query (질의)
관련 페이지 검색(index.md 또는 단순 검색) → **출처를 명시**해 합성 답변 → 재사용 가치 있는 답은 새 위키 페이지로 환류 저장.

## Lint (점검)
주기적 건강검진. 찾는 것:
- 페이지 간 **모순**
- 새 자료에 의해 밀려난 **오래된 주장**
- inbound 링크 없는 **고아 페이지**
- 빠진 상호 참조
- 언급되지만 **자체 페이지가 없는 중요 개념**

모순은 자동 해소하지 않고 [[typed-edges]]로 *보존*하며, lint는 오히려 *누락된* 모순 표시를 찾는다. 삭제는 제안만.
