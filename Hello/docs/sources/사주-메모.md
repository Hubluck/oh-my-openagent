# (Source) 사주 메모

> 원본: `raw/sources/사주-원본.md` (개인 메모, 한국어)

## 3줄 요약
- 사주 = 동아시아 전통 명리학 기반 운세 해석 체계. 태어난 **연·월·일·시**로 8글자(팔자)를 뽑아 성향·운을 해석.
- 구성: 사주팔자 / 대운 / 세운 / [[오행]] / [[십성]].
- 한국에선 사업운·재물운·인간관계·이직/창업 시기 등을 많이 본다.

## 핵심 포인트
- 사주의 정의와 구성 요소 → [[사주]]
- 오행(목화토금수)의 균형 분석, 강한 기운별 성향 → [[오행]]
- 돈·명예·사업·인맥 역할 해석 = [[십성]]
- 흥미점: 유통·정보 흐름이 강한 사주를 이커머스·리셀 분야와 맞다고 해석하기도 함 (참고용)
