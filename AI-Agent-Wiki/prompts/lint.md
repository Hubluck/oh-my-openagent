# Lint Prompt

```text
이 Obsidian AI 업무 위키를 lint 해줘.

점검 항목:

1. raw 원본이 수정되었거나 wiki 영역에 섞여 있지 않은가?
2. 중요한 wiki 문서가 index.md에 누락되어 있지 않은가?
3. 중요한 작업이 log.md에 기록되어 있지 않은가?
4. 5필터를 통과하지 못한 일회성 정보가 wiki에 저장되어 있지 않은가?
   - 검증되지 않은 추측, 사소한 중간 생각, 출처 없는 결정, 오래된 규칙
5. 민감정보 / API 키 / 토큰 / 고객 개인정보가 저장되어 있지 않은가?
6. 끊긴 wiki 링크가 있는가?
7. frontmatter (type, date, status) 누락 문서가 있는가?

보고 형식: 파일별로 문제와 수정 제안을 표로 정리. 자동 수정 가능한 항목은 적용해도 되는지 먼저 확인.

검증 기준: lint 통과 후 다시 lint를 돌렸을 때 모든 항목이 ✅여야 정상.
```
